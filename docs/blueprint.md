# **App Name**: InternMatch AI

## Core Features:

- Profile Input: Collects user's education, skills, interests, and location preferences through a simple form.
- Internship Filtering Tool: AI-powered tool analyzes user input and filters internships based on relevance.
- Recommendation Display: Displays 3-5 internship recommendations in a clear, card-based format, with minimal text and visual cues.
- Mobile Compatibility: Ensures the application is fully responsive and accessible on mobile devices.
- Sector Interest Selection: Allows users to select their preferred sector from a pre-defined list (e.g., IT, Healthcare, Education).
- Skill Tagging: Allows candidates to tag their profiles with soft and hard skills relevant to various internship opportunities.

## Style Guidelines:

- Primary color: Soft blue (#7EC4CF) for a calming, trustworthy feel, reflecting the professionalism of the internship scheme while remaining approachable.
- Background color: Very light blue (#EBF4F8) for a clean, distraction-free interface.
- Accent color: Warm orange (#FFB347) to highlight key actions and draw attention without overwhelming users.
- Body and headline font: 'PT Sans', a humanist sans-serif, to offer a blend of modernity and approachability that suits users with varied levels of digital literacy.
- Simple, easily recognizable icons to aid navigation and understanding, particularly beneficial for first-generation learners.
- Clean, card-based layout for internship recommendations, emphasizing key details with ample spacing to avoid visual clutter.
- Subtle transitions and feedback animations to guide users through the application, enhancing usability without being distracting.
